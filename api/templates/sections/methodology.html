10. Standards and Methodology Used

This emissions report has been prepared in accordance with the following standards and guidance:

  • GHG Protocol Corporate Standard - The primary methodology used for calculating corporate emissions
  • GHG Protocol Scope 2 Guidance - For reporting Scope 2 emissions using both location and market-based methods
  • GHG Protocol Corporate Value Chain (Scope 3) Standard - For identifying and calculating Scope 3 emissions
